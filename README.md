## 🏛️ Design Concept: The Digital Atelier

This website departs completely from conventional cyber/HUD/terminal cliches. It is engineered with the design maturity of an architectural monograph and the product precision of Apple, Linear, and Vercel:

- **Palette**: Pure Obsidian canvas (`#090909`), warm ivory typography (`#F5F5F0`), muted slate metadata, and a single electric cobalt accent (`#3B82F6`).
- **Spatial Computing**: Translucent refractive glass and brushed titanium hero sculpture rendered in React Three Fiber with organic mouse parallax.
- **Narrative Scroll**: Fluid, continuous editorial flow with Lenis smooth scrolling.
- **Micro-Interactions**: Adaptive cursor with contextual mode switching (`VIEW PROJECT ↗`), smooth number counters, and responsive mobile architecture.

## ⚡ Local Development

```bash
# Clone the repository
git clone https://github.com/Sumit692/sumit-portfolio.git

# Install dependencies
npm install

# Run the development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

```bash
# Build for production
npm run build

# Start production server
npm start
```
