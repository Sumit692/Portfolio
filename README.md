* Artificial Intelligence & Machine Learning

* Backend Engineering
* Interactive 3D Experiences
* Software Development
* Competitive Programming & DSA

The goal is to communicate not only **what I build**, but also how I approach engineering, design, problem solving, and continuous learning.

# 🎨 Design Philosophy

The portfolio intentionally avoids the typical developer-portfolio aesthetic of:

* Neon cyberpunk interfaces
* Terminal-inspired layouts
* Excessive gradients
* HUD-style dashboards
* Overloaded animations

Instead, the design follows a **digital atelier / architectural editorial** direction.

### Visual Language

* Obsidian background
* Warm ivory typography
* Muted metadata
* Cobalt accent lighting
* Large editorial typography
* Generous whitespace
* Glass-like surfaces
* Architectural 3D elements
* Minimal interface controls

The design is intended to make the engineering work feel like a curated body of work rather than a collection of isolated projects.

# ⚡ Getting Started

## Prerequisites

Make sure you have installed:

* Node.js 20+
* npm
* Git

## Clone the Repository

```bash
git clone https://github.com/Sumit692/sumit-portfolio.git

cd sumit-portfolio
```

## Install Dependencies

```bash
npm install
```

## Start Development Server

```bash
npm run dev
```

Open:

```text
http://localhost:3000
```

---

# 📦 Production Build

Create an optimized production build:

```bash
npm run build
```

Start the production server:

```bash
npm start
```

Run linting:

```bash
npm run lint
```

# 🚀 Deployment

The portfolio is optimized for deployment on **Vercel**.

Typical deployment flow:

```text
GitHub Repository
        │
        ▼
     Vercel
        │
        ▼
Production Build
        │
        ▼
Live Portfolio
```

The application uses Next.js App Router and is configured for production deployment.
